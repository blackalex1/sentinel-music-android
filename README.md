# Sentinel Music Android

Мобильное приложение для прослушивания музыки с домашнего сервера Sentinel Music на смартфонах Android.

## Возможности

- **Фоновое воспроизведение:** музыка продолжает играть при выключенном экране и блокировке телефона.
- **Управление в шторке:** переключение треков, пауза и отметки «Нравится» прямо на экране блокировки.
- **Офлайн-режим:** возможность сохранять любимые треки в память телефона и слушать их без интернета.
- **Тексты песен:** режим караоке со словами песни, которые подсвечиваются синхронно с музыкой.
- **Быстрый вход:** подключение к домашнему серверу за пару секунд по QR-коду с экрана компьютера.
- **Проверка обновлений:** приложение умеет само проверять наличие свежих версий на GitHub.

## Установка

Вы можете скачать готовый файл приложения:
- **`Sentinel-Music-v0.0.1.apk`** со страницы [Релизов на GitHub](https://github.com/blackalex1/sentinel-music-android/releases).

## Сборка из исходного кода

```bash
# Сборка установочного APK-файла
./gradlew assembleDebug
```

Готовый файл появится в папке `app/build/outputs/apk/debug/app-debug.apk`.
