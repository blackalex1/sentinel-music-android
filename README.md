# Sentinel Music Android

Нативный мобильный клиент под Android для экосистемы домашнего музыкального стриминга **Sentinel Music**.

Разработан на **Kotlin** с использованием декларативного UI фреймворка **Jetpack Compose** и аудиоядра **AndroidX Media3 (ExoPlayer)**.



## ⚡ Возможности приложения

- **Фоновое воспроизведение (MediaSessionService & Foreground Service):**
  - Непрерывное воспроизведение при выключенном экране и блокировке устройства.
  - Полнофункциональное управление воспроизведением в шторке системных уведомлений и на экране блокировки (Play/Pause, Next/Prev, Like).
- **Стриминг высокого качества (Media3 ExoPlayer):**
  - Быстрый стриминг тяжелых lossless файлов FLAC и MP3.
  - Умное упреждающее кэширование и бесшовное переключение треков (Gapless Playback).
  - Поддержка офлайн-сохранения треков на устройство (`OfflineManager`).
- **Синхронизированные караоке-тексты:**
  - Плавная прокрутка строк текста песни в реальном времени с подсветкой текущей фразы по миллисекундам.
  - Оптимизированный бинарный поиск текущей строки за $O(\log N)$.
- **Умный режим «Поток»:**
  - Быстрый запуск персональной волны треков в один тап.
  - Оценка треков (лайки и дизлайки) для обучения рекомендательного вектора на сервере.
- **Подключение к серверу:**
  - Подключение по LAN IP или доменному имени.
  - Автоматическое сохранение сессии и токена авторизации.

## 🛠 Технологический стек

- **Язык:** Kotlin 2.x
- **UI:** Jetpack Compose (Material 3)
- **Аудиодвижок:** AndroidX Media3 (ExoPlayer 1.3+)
- **Сеть:** OkHttp, Retrofit / Ktor Client, Coroutines & Flow
- **Архитектура:** Clean Architecture / MVVM (domain, data, presentation, player)
- **Изображения:** Coil Compose (кэширование обложек треков)

## 🏗 Сборка проекта

### Требования
- JDK 17 или новее
- Android SDK (API 34+)

### Сборка Debug APK:
```bash
gradlew.bat assembleDebug
```
Собранный `.apk` появится в каталоге `app/build/outputs/apk/debug/`.
